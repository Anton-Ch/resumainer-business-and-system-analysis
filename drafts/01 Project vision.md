## 2. Project Summary

The project is a web application that allows registered users to maintain a structured professional profile and generate adapted resume versions for specific job vacancies.

Users enter detailed information about themselves once: contact details, skills, values, achievements, work experience, education, certifications, projects, volunteering, hobbies, languages, and professional aspirations. Then, for each target vacancy, the user provides a job description and company information. The system uses an AI model selected by the user to generate one or more adapted resume versions. Also with tailoring version for ATS (Applicant Tracking System) which creates resume specifically formatted and optimized to be read, parsed, and ranked by automated software used by employers. It ensures your application passes electronic screening, which up to 99% of large companies use to filter candidates before a human reads the resume.

Generated resume versions can be reviewed, edited, saved, downloaded as a print-friendly PDF, and shared through a permanent public URL.

## 3. Core Problem

Job seekers often need to adapt their resume for different vacancies, but doing this manually is time-consuming, inconsistent, and mentally tiring. Many candidates have valuable experience but struggle to select the most relevant details, phrase them clearly, and align their profile with a specific job posting.

## 4. Product Goal

The goal is to help users generate targeted, editable, and reusable resume versions based on a structured personal profile and a specific vacancy description.

## 5. Primary Users

The primary users are:
- Job seekers who apply to different roles.
- Career changers who need to reposition their previous experience.
- Junior IT specialists who need to adapt their resume for internships, trainee programs, and junior roles.
- Business analysts, developers, QA engineers, and other IT professionals who want to maintain multiple resume versions.

## 6. Business Value

The product creates value by:
- Reducing time spent on manual resume adaptation.
- Helping users keep an up to date structured professional profile.
- Supporting multilingual resume generation.
- Allowing users to keep a history of generated resumes.
- Preparing a foundation for future monetization through subscriptions or pay-per-generation in case of high demand.

## 8. Product Vision Statement

For job seekers who need to adapt resumes for different vacancies, the AI-Assisted Resume Tailoring Platform is a web application that stores structured professional profile data and generates targeted resume versions using AI. Unlike generic resume builders, the product focuses on vacancy-specific adaptation, multilingual output, saved resume versions, and shareable PDF-based public links.
