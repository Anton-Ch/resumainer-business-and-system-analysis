## 2. Usage Rules and Controlled Values

### 2.1 General Usage Rules

- Use stable IDs for all records.
- Do not delete historical records; change their status instead.
- Keep descriptions short but specific.
- Use only the controlled values defined in this document.
- Add details only for records that require explanation.
- Update `Last Updated` when meaningful changes are made.
- Keep this document useful and proportional to project size.

### 2.2 Document Status Values

| Value | Meaning | When to Use |
|---|---|---|
| Active | The document is currently maintained | Default for live logs and registers |
| Archived | The document is kept for history but no longer updated | Use after project completion or replacement |
| Superseded | The document was replaced by a newer artifact | Use when another document becomes the official source |

### 2.3 Record Status Values

| Value | Meaning | When to Use |
|---|---|---|
| Draft | Record is created but not yet reviewed | Initial placeholder or early idea |
| Open | Record is active and needs action | Unresolved item |
| In Review | Record is being reviewed | Pending clarification or approval |
| Approved | Record is accepted | Approved decision/change/requirement |
| Rejected | Record is not accepted | Rejected option or request |
| Implemented | Record was applied in documentation or code | Change or decision has been executed |
| Closed | No further action is required | Final state after completion |
| Superseded | Record was replaced by another record | Use when a newer decision or item replaces it |
